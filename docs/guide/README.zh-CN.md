## 三十秒版本

- 发送端把文件切成小块，用**喷泉码**生成一个永不重复的数据包流；每个数据包加上 CRC 和 **Reed–Solomon** 纠错，成为一个**码字**。
- 每一帧是一个彩色格子网格（默认每格 2 比特），装着十几到几十个码字。网格宽高自适应、铺满屏幕，格子大小跟随屏幕的物理尺寸。
- 接收端拍到任意一帧，就收下其中能解出的码字；码字之间互相独立，半张模糊的帧也有用。
- 不论丢了哪些帧，只要收到的不同数据包比文件的符号数多两三个，文件就能还原，不用等下一轮去补漏掉的帧。
