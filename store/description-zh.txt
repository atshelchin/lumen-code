Lumen Code 把文件从一块屏幕传到手机相机。发送端把文件播放成彩色动态码，接收端用相机对准屏幕，就能还原出文件。不需要网络、蓝牙、配对或账号，文件只在两台设备之间传递。

适合
- 在不同品牌的设备之间传文件或一段文字。
- 没有共同网络、受管控或物理隔离的电脑。
- 从一块只能看的屏幕上拷下内容。

怎么用
1. 在有文件的设备上打开“发送”，选择文件或输入文字。
2. 在另一台手机上打开“接收”，用相机对准屏幕。
3. 保持稳定，收完后打开、保存或分享。

每一帧都是新数据，漏掉或拍糊几帧只会让传输稍慢一点；四个角看到三个就能读出一帧。文字、链接和 JSON 直接阅读，图片和其他文件可以保存或分享。

速度
取决于屏幕和相机。两台手机之间用应用实测最快 96 KB/s；按 50 KB/s 计算，1 MB 约 20 秒。单个文件最大 256 MB。

各平台互通
iPhone 应用、Android 应用、桌面版和 lumencode.link 上的免费网页版用同一套开放协议，可以互相收发。

隐私
应用不发起任何网络连接，没有账号，也没有统计。相机画面只在设备上处理，不保存也不发送。

光敏提示
发送时，码会以每秒最多 60 次的频率闪烁变色。对闪光敏感的人（例如光敏性癫痫患者）请不要注视。第一次播放前，应用会请你确认。
